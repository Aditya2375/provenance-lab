HOW THE EXPERIMENT WORKS

Hold out pages.
Then hold out a generator.

TSM-Bench English paragraph-writing pairs. Wikipedia targets vs GPT-4o alternatives. Deterministic SHA-256 page-title split: 70/15/15 train/validation/test. Same-page pairs stay together. Exact texts shared between splits are removed.

BERT-Tiny, 4.43M base parameters, 128-token limit, three epochs on CPU. Epoch picked by validation AUROC. Decision threshold picked by validation accuracy. Mistral alternatives are evaluated only on held-out test-page IDs.

Training: 3,604 examples / 1,569 pages. Validation: 749 examples / 320 pages. Test: 779 examples / 335 pages. Class balance is approximate after duplicate/minimum-length filtering.

WHAT DOES NOT TRANSFER

Style is not identity.

Non-native English, edits, quotes, mixed authorship, new models, other domains and short text can all invalidate the learned patterns. False positives are substantial. Detection cannot prove plagiarism or establish a person's intent.

This is a dataset-specific portfolio experiment, not a production detector. The stronger lexical baseline is reported rather than hidden. An unseen-generator test is not a full out-of-domain benchmark.

Dataset: Gerrit Quaremba, Denny Vrandecic, Elizabeth Black and Elena Simperl, TSM-Bench (ICLR2026), CC BY-NC-SA4.0. Personal/non-commercial use. Weights fine-tuned from Google's BERT miniature, Apache2.0 base. Model/data provenance and exact revisions are in the repository.
